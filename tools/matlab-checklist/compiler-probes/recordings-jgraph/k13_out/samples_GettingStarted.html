Getting Started with the k13s Python Package

  1. Install the JGraph Runtime 0.2.3, or set JGRAPH_RUNTIME_ROOT to its folder, or put its runtime\win64 folder on the PATH.
  2. Install the package from this folder with python -m pip install ., or put this folder on PYTHONPATH.
  3. In Python, import the package, then the matlab module, and call the functions through the handle initialize() answers: 
    import k13s
import matlab
handle = k13s.initialize()
result = handle.functionName(matlab.double([1, 2, 3]))
handle.terminate()
  4. Run the program: 
    python driverApplication.py
