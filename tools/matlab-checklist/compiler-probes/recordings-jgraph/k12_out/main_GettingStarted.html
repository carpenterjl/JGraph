Getting started with the k12lib C++ shared library

  1. Install the JGraph Runtime 0.2.3, or set JGRAPH_RUNTIME_ROOT to its folder, and put its runtime\win64 folder on the PATH.
  2. Include k12libv2.hpp (in v2\generic_interface) in one source file of the program, compile with the runtime's include folder and C++17, and link with jgrt.lib: 
    cl /std:c++17 /EHsc /I "%JGRAPH_RUNTIME_ROOT%\include" /I v2\generic_interface driverApplication.cpp "%JGRAPH_RUNTIME_ROOT%\lib\win64\jgrt.lib"
  3. In the program, start the runtime with matlab::cpplib::initMATLABApplication, open k12lib.ctf with initMATLABLibrary, and call its functions through the header or with feval. A program written for MATLAB's runtime compiles as it is: the runtime's headers name their jgraph namespace matlab too.
  4. Keep k12lib.ctf beside the program, in the folder it runs in, or in the folder CPPSHARED_BASE_CTF_PATH names.
