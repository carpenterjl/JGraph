  |k17xl JGraph Excel Add-in 
  |
  |1. Prerequisites for Deployment 
  |
  |Verify that the JGraph Runtime (0.2.3) is installed on the computer that
  |runs Excel. If not, install it from its installer, or set JGRAPH_RUNTIME_ROOT to the folder
  |of a JGraph Runtime carried along.
  |
  |The add-in is a COM server: register k17xl_1_0.dll once on that computer by running
  |_install.bat beside it (for every user when run as an administrator, else for the current
  |user alone), then open the add-in workbook in Excel or call the component from VBA.
  |
  |2. Files to Deploy and Package
  |
  |-k17xl_1_0.dll (output from mcc)
  |-The JGraph Runtime installer, when the computer has no JGraph Runtime
  |-This readme file
  |
  |NOTE: Verify that k17xl_1_0.dll is registered on the target machine. If registration fails,
  |      run _install.bat from a command prompt and read what it prints.
  |
  |3. Definitions
  |
  |An Excel add-in is a COM DLL whose class exposes the MATLAB functions in its deployable
  |archive (embedded in the DLL, or the .ctf beside it) as methods Excel's VBA calls on the
  |JGraph Runtime; the .bas module declares a worksheet function for each, and the add-in
  |workbook carries that module into Excel.

  |
  |:START
  |SETLOCAL
  |set FILE=k17_one_1_0.dll
  |ECHO Registering %FILE%...
  |where MWRegsvr 1>NUL 2>&1
  |if ERRORLEVEL 1 GOTO USEREGSVR
  |
  |MWRegsvr %FILE%
  |IF ERRORLEVEL 1 GOTO :USERONLYREG
  |GOTO :SUCCESS
  |
  |:USERONLYREG
  |ECHO.
  |SET YOURINPUT=
  |Set /P YOURINPUT=Do you want to register the component for YOU only? [Y]es or [N]o:
  |IF NOT "%YOURINPUT%"=="" SET YOURINPUT=%YOURINPUT:~0,1%
  |IF /I "%YOURINPUT%" == "Y" (
  |  ECHO Registering the component for you only...
  |    MWRegsvr /useronly %FILE%
  |  if ERRORLEVEL 1 GOTO FAILURE
  |  GOTO SUCCESS
  |)
  |ECHO Did not register the component.
  |GOTO END
  |
  |:USEREGSVR
  |REM if mwregsvr is not available use regsvr32
  |ECHO Using regsvr32 to register the component...
  |regsvr32 %FILE%
  |GOTO SUCCESS
  |
  |:FAILURE
  |ECHO Failed to register the component.
  |GOTO END
  |
  |:SUCCESS
  |ECHO Please refer to the documentation for any additional setup steps.
  |GOTO END
  |
  |:END
  |ENDLOCAL
  |ECHO.

  |k17_one JGraph Excel Add-in 
  |
  |1. Prerequisites for Deployment 
  |
  |Verify that the JGraph Runtime (0.2.3) is installed on the computer that
  |runs Excel. If not, install it from its installer, or set JGRAPH_RUNTIME_ROOT to the folder
  |of a JGraph Runtime carried along.
  |
  |The add-in is a COM server: register k17_one_1_0.dll once on that computer by running
  |_install.bat beside it (for every user when run as an administrator, else for the current
  |user alone), then open the add-in workbook in Excel or call the component from VBA.
  |
  |2. Files to Deploy and Package
  |
  |-k17_one_1_0.dll (output from mcc)
  |-The JGraph Runtime installer, when the computer has no JGraph Runtime
  |-This readme file
  |
  |NOTE: Verify that k17_one_1_0.dll is registered on the target machine. If registration fails,
  |      run _install.bat from a command prompt and read what it prints.
  |
  |3. Definitions
  |
  |An Excel add-in is a COM DLL whose class exposes the MATLAB functions in its deployable
  |archive (embedded in the DLL, or the .ctf beside it) as methods Excel's VBA calls on the
  |JGraph Runtime; the .bas module declares a worksheet function for each, and the add-in
  |workbook carries that module into Excel.

  |k17m JGraph Excel Add-in 
  |
  |1. Prerequisites for Deployment 
  |
  |Verify that the JGraph Runtime (0.2.3) is installed on the computer that
  |runs Excel. If not, install it from its installer, or set JGRAPH_RUNTIME_ROOT to the folder
  |of a JGraph Runtime carried along.
  |

  |_install.bat beside it (for every user when run as an administrator, else for the current
  |user alone), then open the add-in workbook in Excel or call the component from VBA.
  |
  |2. Files to Deploy and Package
  |
  |-k17m_1_0.dll (output from mcc)
  |-k17m.bas (VBA module file created by mcc)
  |-The JGraph Runtime installer, when the computer has no JGraph Runtime
  |-This readme file
  |
  |NOTE: Verify that k17m_1_0.dll is registered on the target machine. If registration fails,
  |      run _install.bat from a command prompt and read what it prints.
  |
  |3. Definitions
  |
  |An Excel add-in is a COM DLL whose class exposes the MATLAB functions in its deployable
  |archive (embedded in the DLL, or the .ctf beside it) as methods Excel's VBA calls on the
  |JGraph Runtime; the .bas module declares a worksheet function for each, and the add-in
  |workbook carries that module into Excel.
