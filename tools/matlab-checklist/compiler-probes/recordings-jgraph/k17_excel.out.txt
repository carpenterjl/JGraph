  |k17xl JGraph Excel Add-in 
  |
  |1. Prerequisites for Deployment 
  |
  |Verify that the JGraph Runtime (0.2.3) is installed on the computer that
  |runs Excel. If not, install it from its installer, or set JGRAPH_RUNTIME_ROOT to the folder
  |of a JGraph Runtime carried along.
  |
  |The add-in is a COM server: register k17xl_1_0.dll once on that computer by running
  |_install.bat beside it (for every user when run as an administrator, else for the current
  |user alone), then open the add-in workbook in Excel or call the component from VBA.
  |
  |2. Files to Deploy and Package
  |
  |-k17xl.ctf (component technology file)
  |-k17xl_1_0.dll (output from mcc)
  |-The JGraph Runtime installer, when the computer has no JGraph Runtime
  |-This readme file
  |
  |NOTE: Verify that k17xl_1_0.dll is registered on the target machine. If registration fails,
  |      run _install.bat from a command prompt and read what it prints.
  |
  |3. Definitions
  |
  |An Excel add-in is a COM DLL whose class exposes the MATLAB functions in its deployable
  |archive (embedded in the DLL, or the .ctf beside it) as methods Excel's VBA calls on the
  |JGraph Runtime; the .bas module declares a worksheet function for each, and the add-in
  |workbook carries that module into Excel.
