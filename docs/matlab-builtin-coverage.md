# MATLAB builtin coverage

Where JGraph stands against the 515 commands the R2021b documentation lists with kind **builtin**
(514 distinct names; one appears twice). The live tracker is `matlab-r2021b-documented.html` in the
demo workspace, regenerated by `tools/matlab-checklist/build-checklist.py`; this file is the standing
summary, so the shape of what is left does not have to be re-derived each time.

**364 of 514 implemented** as of M43 (363 after M39, 326 after M38, 185 after M37, 109 after M36).
Across every callable kind — builtin, function, operator, keyword, script — the count is 556 of
2,027; the M41–M43 stress-test campaign added the language features (`persistent`, nested
functions, N-D arrays, implicit expansion), numerics (`sparse`/`sprand`/`eigs`/`spy`, `ode45`,
`sqrtm`/`logm`/`cond`, the integer classes), and data types (`table`/`timetable`, `categorical`,
`string`/`cellstr`/`compose`/`missing`) that the twenty stress scripts exercise, most of which the
documentation lists under kinds other than builtin.

The remaining 150 divide into six families that each need machinery JGraph does not have, plus a
short list of eleven odds and ends. Every one of them is accounted for below.

## Answers that follow from JGraph's value model

These are deliberate, not oversights, and are documented in the scripting guide:

- Every number is a double, so `isinteger` is always false and `intmax` reports its limit as a double.
- There is no string-array type: text is `char`, so `isstring` is always false and the three
  `convert*Strings*` functions hand the value straight back.
- A vector written as a literal is a row, so `isrow([1 2 3])` is true; orientation appears where
  MATLAB produces it — `A(:)`, `A(:, j)`, transpose, `find` on a matrix — and `iscolumn` reads it.
  One leniency remains: stacking vectors where any of them is a column reads them all as columns, so
  `[audio; zeros(k, 1)]` pads a signal that came from a reader with no orientation to give (ADR 0043).
- Since M42 a real sparse class exists (CSC storage behind `sparse`/`sprand`/`eigs`/`spy`/`lu`),
  and `issparse`/`full`/`nnz` answer for whichever storage a value has. Sparse indexing, `find`,
  `\`, and transpose are not implemented yet — each errors by name with `full()` as the escape
  hatch. `class(sparse(...))` is `double`, as in MATLAB.
- Since M43, `table(...)` and `timetable(...)` construct real tables; a *categorical* is its cell
  of category names, a *duration* is its number of seconds, and *missing* is a sentinel string —
  untyped stand-ins that carry the shapes scripts consume, without the class names.
- The integer classes `int8`…`uint64` are MATLAB conversions (round half away from zero, saturate,
  NaN to 0) on double storage, with `.empty(m, n)` statics; `class(uint8(5))` still says `double`.
- `dec2bin` and friends give a string for one value and a cell of strings for an array, because
  JGraph has no char matrix to return.
- `schur` produces the real form only. Its 2×2 blocks hold the conjugate pairs, which is the whole
  point of the real form; the complex form would need a unitary factor that no other builtin here
  could consume.
- The console-session settings — `echo`, `more`, `beep`, `fftw`'s planner — are kept and reported
  but change nothing, because JGraph's console is a pane in an application rather than a teletype
  and its transform has no plan to tune. `recycle('on')` is the exception: it is refused rather than
  accepted, because a caller turns it on precisely so that a mistake stays recoverable.
- `input` reads from the process's console. That exists under `jgraph -batch` and does not inside
  the workspace window, where the call reports so rather than hanging.

## Known differences worth fixing

Both entries that stood here — `A(i, j)` not being two-subscript indexing, and `true == 1` being
false — were fixed in M40 (ADR 0043). Arrays now carry a rows-by-columns shape over column-major
storage, so two subscripts, `A(:)`, column-major linear indexing, growth, deletion and a genuinely
transposed vector all behave as MATLAB does; and a logical compares equal to the number it stands
for, with `NaN == NaN` false.

Nothing is recorded here at present.

## Not implemented — 150

### Handle graphics and app building — 44

`addpoints` `ancestor` `animatedline` `axes` `clearpoints` `copyobj` `fill` `fill3` `findobj`
`frame2im` `gcbo` `gco` `get` `getpoints` `groot` `hggroup` `hgsetget` `hgtransform` `im2frame`
`isgraphics` `ishandle` `ishghandle` `light` `line` `patch` `plot3` `polaraxes` `rectangle` `reset`
`rmappdata` `selectmoveresize` `set` `setappdata` `surface` `text` `uicontextmenu` `uicontrol`
`uimenu` `uipanel` `uipushtool` `uitoggletool` `uitoolbar` `waitfor` `waitforbuttonpress`

`get`/`set`/`findobj` need a handle value type over the figure object model; the figure is edited
through the browser and inspector instead. Six of these are not about handles at all but about
drawing primitives JGraph's figure model does not have yet — `fill`, `fill3` and `patch` need a
filled-polygon plot object, `plot3` a 3-D line one, `line` and `text` the primitive forms of what
`plot` and `title` already do. Each of those is a figure-model slice (object, renderer, `.graph`
serialization, inspector) rather than a builtin, which is why they are not in a builtin-coverage
milestone. They are the most useful thing left on this list.

### .NET, Java, Python, C++, MEX, and COM interop — 34

The `NET.*`, `clib*`, `java*` and `py*` families, plus `calllib` `libisloaded` `unloadlibrary`
`mex` `mexhost` `actxGetRunningServer` `winqueryreg` `import` `isjava` `jenv`.

JGraph does not host other runtimes from a script. (It runs Python and C# as *engines* — a whole
script in that language — which is a different thing from calling into them mid-expression.)

### OOP and metaclass plumbing — 19

These exist to customize the behaviour of user-defined classes, which JGS does not have.

### Sparse reorderings and incomplete factorizations — 10

`amd` `dissect` `dmperm` `etree` `ichol` `ilu` `nzmax` `speye` `symbfact` `symrcm`

The sparse storage type itself landed in M42 (`sparse` moved to implemented, with `sprand`, `eigs`,
`spy`, and a Gilbert–Peierls `lu`); these are the fill-reducing orderings and incomplete
factorizations that layer on top of it, and `speye`/`nzmax` are small additions behind the same
seam.

### Console debugger — 11

`dbclear` `dbcont` `dbdown` `dbquit` `dbstack` `dbstatus` `dbstep` `dbstop` `dbtype` `dbup`
`keyboard`

JGraph debugs through the editor: breakpoints in the margin, step buttons, a Workspace pane. A
parallel console debugger would be a second, worse interface to the same thing.

## Keeping this current

`tools/matlab-checklist/build-checklist.py` reads the implemented set straight out of
`JgsBuiltinCatalog.cs`, so re-running it after any milestone that adds builtins refreshes the tracker
without editing anything by hand:

```
python tools/matlab-checklist/build-checklist.py <workspace>/matlab-r2021b-commands.html <workspace>/matlab-r2021b-documented.html
```

Update the counts here at the same time.
