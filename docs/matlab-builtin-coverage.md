## Answers that follow from JGraph's value model

These are deliberate, not oversights, and are documented in the scripting guide:

- Every number is a double, so `isinteger` is always false and `intmax` reports its limit as a double.
- There is no string-array type: text is `char`, so `isstring` is always false and the three
  `convert*Strings*` functions hand the value straight back.
- Vectors carry no orientation, so `isrow` is true for any vector and `iscolumn` only for a scalar.
- Storage is always dense: `issparse` is false, `full` is the identity, and `nnz`/`nonzeros` answer
  for dense data.
- `dec2bin` and friends give a string for one value and a cell of strings for an array, because
  JGraph has no char matrix to return.

## Known differences worth fixing

Two things a MATLAB script can notice that are not builtin coverage at all:

- **`A(i, j)` is not two-subscript indexing.** A JGraph matrix is an array of row arrays, indexed
  `A(i)(j)` (`docs/jgs-scripting-guide.html`). This is the largest single fidelity gap left and is
  its own milestone: it touches the parser, the indexing path, and assignment.
- **`true == 1` is false.** `JgsValue.AreEqual` requires matching types, so a logical never equals a
  number under `==`, `isequal`, `ismember`, or a `switch` case. MATLAB treats logicals as numeric.
  Changing it is a one-place fix with a wide blast radius, so it is recorded rather than done.

## Excluded, deliberately — 142

Each of these needs machinery JGraph does not have and is not planning. They are excluded as
families, not one at a time, so the tracker's remaining count stays meaningful.

| Family | Count | Why |
|---|---|---|
| .NET / Java / Python / C++ / MEX / COM interop | 45 | JGraph does not host other runtimes from a script. |
| Handle graphics and app building | 44 | `get`/`set`/`findobj`/`patch`/`uicontrol` need a handle value type over the figure object model. Real work, and its own milestone if wanted — the figure is edited through the browser and inspector instead. |
| `pattern` objects | 21 | The R2020b pattern API is a value type of its own; plain regular expressions cover the same ground and are implemented. |
| OOP and metaclass plumbing | 15 | `subsref`/`subsasgn`/`metaclass`/`loadobj` exist to customize user classes, which JGS does not have. |
| Console debugger (`db*`, `keyboard`) | 12 | JGraph debugs through the editor: breakpoints in the margin, step buttons, a Workspace pane. A parallel console debugger would be a second, worse interface to the same thing. |
| Sparse matrices and reorderings | 11 | Needs a sparse storage type through the numerics stack; the reordering functions (`amd`, `symrcm`, `dissect`, …) only make sense once it exists. |
